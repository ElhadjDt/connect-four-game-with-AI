# Connect Four Game

Connect Four is a strategic board game where two players take turns dropping discs into a 6-row by 7-column grid. The first player to align four discs horizontally, vertically, or diagonally wins the game.

This project implements Connect Four in C++ with a simple command-line interface. The game allows you to play against an AI.


## Installation

To play Connect Four, follow these steps:

1. **Clone the Repository**
```bash
git clone https://github.com/ElhadjDt/connect-four-game-with-AI.git
cd connect-four-game-with-AI
```

2. **Compile the Program**

This project is written in standard C++ and does not require any external libraries.
You can compile it using g++ or any C++11+ compatible compiler.

On Linux / macOS
```bash
g++ main.cpp -o connect4
```
On Windows (MinGW)
```bash
g++ main.cpp -o connect4.exe
```

3. **Run the Game**
   
Linux / macOS
```bash
./connect4
```

Windows
```bash
connect4.exe
```
